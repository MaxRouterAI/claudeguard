# 隐私与网络范围

当前预览版无需账号，无遥测、远程推送或营销请求。

普通检测会读取本机代理、监听端口及进程路径、路由、DNS、IPv6本地地址、时区、少量非认证环境变量、已安装程序元数据和静态签名。不会读取Claude账号、对话、配置、密钥、Keychain、shell启动文件或代理订阅。

唯一主动诊断目标为固定Cloudflare HTTPS trace，必须经过配置中的`127.0.0.1` HTTP代理，失败不尝试直连，不跟随重定向，不关闭证书验证。Cloudflare会看见代理出口请求；不随请求发送账号、Cookie或认证头。离线目录中的Anthropic/Claude及其他域名只作为文字，不做HTTP、TLS或DNS测试。

完整出口IP只在Rust内存比较，不展示、写盘、放进IPC或复制报告。事件只留内存最近8条。自己的设置文件仅包含版本、代理地址、进程路径、地区/时区偏好与通知开关，不允许把用户名/密码放进代理URL。

`--observe-only` 进行上述真实检测，但在后端禁止该进程启动客户端；配置修改、UI 或后台恢复均不能解禁。它仍只请求固定 Cloudflare，不请求 Anthropic。

`--demo`使用模拟适配器，不执行上述本机采集、联网或客户端启动；不保存设置或发送系统通知。它的绿色结果不是实际环境检测证据。

用户明确点击真实启动按钮后，客户端会按自己的行为读取账号和访问服务；这不属于检查器的探测。检查器无法保证客户端全部流量、第三方代理内部路由或账号状态。

通知诊断仅读取本应用的通知显示设置，并按唯一测试标识在本应用通知中心记录中匹配，不读取通知正文或其他应用通知。系统接受、通知中心记录和人工确认分别展示；测试序号、查询代际不进入复制报告。用户确认仅存在内存，不能改变网络检查或启动权限。专注模式等系统状态未读取、未修改。

## 首次使用与身份兼容

首次自动发现仅只读系统代理与对应端口的监听进程路径，无外网请求、DNS 探测、端口扫描或 PAC 下载。候选只在界面草稿中，确认保存后才启用固定 Cloudflare 检测；取消不会创建设置。重新发现不会直接替换已有配置。

历史有效设置只在内存迁移，读取不会重写文件。显示名改为 ClaudeGuard，现有 bundle identifier 保留以兼容配置目录和通知权限。真实 GUI 使用同用户本地锁，不传输或转发参数；锁文件不包含网络、账号或配置内容。

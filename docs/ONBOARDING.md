# 首次配置与兼容

新安装没有代理地址、进程路径或地区/时区偏好。默认空配置只能显示首次确认界面，不能检测、监测或启动客户端。GUI、菜单、CLI 检测与共享引擎均拒绝未确认/无效配置。

自动发现只读取系统 HTTP/HTTPS 代理。只有两者开启、均指向同一个 `127.0.0.1` 有效端口、没有 PAC/自动发现且本地唯一显式回环监听者路径可确认，才提供候选。读取前后复核系统配置及进程归属；不读取进程命令行参数，不扫端口、不解析远程代理、不执行 PAC、不发外网请求。端口和进程名称来自实际观测，不硬编码供应商。

候选仅填入草稿。用户核对后保存，才将 `setupConfirmed: true` 与配置原子写入本工具文件，然后完整检查。草稿可手动编辑，地区及非大陆时区偏好可选；重新发现仅更新草稿的代理地址与程序路径，不重置已有偏好。取消不写盘、不扫描。

发现与完整检查是两个阶段。候选过时、代理被替换或设置不符，会在确认后的完整检查中拒绝放行，不能把“识别成功”当作网络正常或程序可信。

设置版本 1 为历史已配置状态：严格解析全部字段后在内存迁移为版本 2、保留代理、地区、时区及通知开关。读取不改写旧文件；下一次明确保存才写入新 schema。版本 2 必须显式包含 `setupConfirmed`，缺失/未知版本/坏 JSON/软链接/超大文件均不能作为已确认配置。

显示名称为 ClaudeGuard；存储与通知 bundle identifier 保留 `dev.claude-environment-guard.preview`，避免预览用户丢失设置和系统通知授权。正式身份迁移须单独设计，不通过改字符串创建另一套配置。

真实与仅观察 GUI 在任何设置读取、事件监听和监测启动前取得同用户文件租约。第二实例拒绝运行，不转发参数，不把仅观察模式切换成可启动模式。命令行只检入口独立执行；离线演示不读取真实设置，不参与真实通知或网络监测。
